## 🚀 How to Use (Everyone Can Now)

### Online
```
https://aseydaaksakal.github.io/cv-studio/
```
No installation needed. Works in browser.

### Local (2-5 minutes)
```bash
# 1. Clone
git clone https://github.com/aseydaaksakal/cv-studio.git
cd cv-studio

# 2. Setup backend
cd backend
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
pytest                          # Verify: 90 tests passing ✅

# 3. Start backend
uvicorn app:app --reload

# 4. Setup frontend (new terminal)
cd web
python -m http.server 8080

# 5. Open browser
http://localhost:8080
```

**See SETUP.md for detailed instructions.**
